### Preferred Partner — ตามหาค่าคอมจริงแล้ว: **Booking ไม่เปิดเผยก่อนสมัคร**

ไล่ดูครบทั้งสามที่ ไม่มีที่ไหนบอกตัวเลข:

| ที่ | เขียนว่าอะไร |
| --- | --- |
| หน้า Preferred Partner Program ในเอ็กซ์ทราเน็ต | *"a small increase in commission"* ไม่มีตัวเลข มีแค่ปุ่ม `Join program` |
| บทความ Partner Help | *"in exchange for a small increase in commission"* ไม่มีตัวเลข |
| Finance → Financial Overview | ไม่แสดงอัตราค่าคอมเลย (ก.ย. ยอด ฿0 จึงไม่มีบรรทัดคอม) |

บทความระบุว่า **"สถานะและจำนวนค่าคอมจะเปลี่ยนทันทีที่กดสมัคร"** แปลว่า
**ตัวเลขจะรู้ก็ต่อเมื่อสมัครไปแล้ว** ซึ่งเป็นการตัดสินใจเรื่องต้นทุน ไม่ใช่เรื่องเทคนิค
**จึงไม่กดให้** ทางที่เหลือคือ ถาม Booking support ตรง ๆ หรือเปิดสัญญา GDT ดู

**สถานะคุณสมบัติตอนนี้ (ผ่านทั้งคู่ แต่เฉียดฉิว):**

| เกณฑ์ | ของเรา | ขั้นต่ำ |
| --- | ---: | ---: |
| Performance score | **70%** | 70% |
| Review score | **8.0** | 7.0 |

Performance score อยู่ที่เส้นพอดี — ถ้าตกไปกว่านี้จะหลุดสิทธิ์ และถ้าถูกถอดออก
จะสมัครใหม่ได้อีกทีหลัง **180 วัน** (Booking วัดคุณสมบัติใหม่ทุก 90 วัน)

## 4. 🟢 Google Ads — สองวันหลังตัดคำค้น สัญญาณดี (แต่ยังเร็วเกินสรุป)

คำค้นที่เข้ามาวันที่ 16 ก.ย. **เป็นคำระบุทำเลล้วนทุกคำ** ไม่มี "ใกล้ฉัน" หลงเหลือ:

| คำค้น | คลิก | Conversions |
| --- | ---: | ---: |
| ที่พัก ใกล้ เมืองทอง | 2 | **3.00** |
| ที่พัก ใกล้ ศูนย์ ราชการ แจ้งวัฒนะ | 2 | 0 |
| ที่พัก ใกล้ ธันเดอร์ โดม เมืองทอง ธานี | 1 | **1.00** |
| โรงแรม ใกล้ อิมแพ็ค เมืองทอง ธานี | 2 | 0 |

**CPC ขึ้นจาก ฿3.91 เป็น ~฿16** — คาดไว้แล้ว เพราะคลิกถูก ๆ ที่ไม่มีค่าหายไป
สิ่งที่ต้องดูคือ cost/conv ไม่ใช่ CPC (฿11.09 ในคำที่ทำงาน)

⛔ Google ยังเชียร์ `Add broad match keywords (+12.6%)` · `Performance Max` ·
`Maximize conversion value (+17.6%)` บนหน้า Recommendations — **อย่ากดทั้งสามอัน**
สองอันแรกขยายปัญหาที่เพิ่งแก้ อันที่สามต้องมีค่า conversion value ซึ่งเรายังไม่ได้ตั้ง
