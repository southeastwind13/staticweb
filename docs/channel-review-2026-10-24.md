## 1. Google Ads — ได้ผล ไม่ต้องแก้อะไรเพิ่ม

- Presence + negative คู่แข่ง 23 คำ (15 ต.ค.): CPA ลด ~36%, CPC ลด 13%, คลิกเท่าเดิม → **คงไว้**
- คำค้นที่ใช้เงินสูงสุดสัปดาห์นี้เป็นคำที่ระบุทำเลทั้งหมด (อิมแพ็ค/เมืองทอง/ชื่อโรงแรม) ไม่เจอคำกว้างแบบ "ใกล้ฉัน" กลับมา
- คีย์เวิร์ดที่ทำงานดีที่สุด: `"โรงแรมใกล้อิมแพ็ค"` 12 conv ฿20.70/conv · `"ที่พักใกล้อิมแพ็ค อารีน่า"` 6 conv ฿22.89
- Business Trip (ชี้หน้าแรกแล้ว): `"ที่พักใกล้ศูนย์ราชการ แจ้งวัฒนะ"` 2 คลิก 2 conv · `"ที่พักใกล้แจ้งวัฒนะ"` 5 คลิก 0 — ยังเล็กเกินจะตัดสิน
- **Landing page experience ยัง `Below average` แทบทุกคีย์เวิร์ด** (QS ส่วนใหญ่ 5/10) — 9 วันหลัง deploy ยังไม่ขยับ → ดูข้อ 2
- ⚠️ **RSA คอนเสิร์ตยังมี headline "ไป Lingorm 17-18 ต.ค.?"** และ description ยังเอ่ยชื่อ Lingorm/LYKN/Nunew — งาน Lingorm จบแล้ว, LYKN จบ 25 ต.ค., Nunew จบ 1 พ.ย.
  เสนอ: เปลี่ยน Lingorm → **"ไป CHOOM 7-8 พ.ย.?"** ตอนนี้ · LYKN → "ไป GMMTV 28 พ.ย.?" หลัง 25 ต.ค. · description → "BIG ASS, GMMTV ที่อิมแพ็ค อารีน่า ..."

## 2. 🟡 เว็บมือถือยังช้า — ต้นตอคือสคริปต์ Google ไม่ใช่รูป

PageSpeed API โควตาหมดอีก จึงรัน Lighthouse 12.6 บนเครื่อง:

| | คะแนน | FCP | LCP |
| --- | ---: | ---: | ---: |
| หน้าแรก (simulated throttling = แบบ PageSpeed) | 68 | 3.4 วิ | 8.7 วิ |
| concert.html (simulated) | 69 | 3.2 วิ | 8.7 วิ |
| หน้าแรก (devtools throttling = โหลดจริงบนเน็ตช้า) | 79 | 2.0 วิ | **5.2 วิ** |

LCP คือรูป hero (`hero-exterior-1200.webp` 130KB) — ค้นเจอเร็ว (preload + fetchpriority ทำงานแล้ว) แต่ **ใช้เวลาโหลด 4.6 วิ (88% ของ LCP)**
เพราะเริ่มโหลดพร้อมกับ:

| ไฟล์ | ขนาด |
| --- | ---: |
| `gtag/js?id=G-CG82G9GPN5` (โหลดจากหน้าเว็บ) | 205KB |
| `gtm.js?id=GTM-PLKLTZT` | 129KB |
| `gtag/js?...&cx=c` (**GTM โหลด gtag ซ้ำอีกรอบ**) | 203KB |
| Font Awesome CSS + 2 ฟอนต์ | 249KB |
| Sarabun TTF | 83KB |

**ข้อเสนอ (ยังไม่ได้ทำ — กระทบระบบวัดผล ต้องตรวจ `/g/collect` หลังแก้ตามกฎใน CLAUDE.md):**
1. เลื่อนโหลด GTM + gtag ไปหลัง `load` (หรือ ~2 วิ) — รูป hero จะได้แบนด์วิดท์เต็ม · คาดว่า LCP ลด 2–3 วิ · เสี่ยง: คนที่เด้งออกเร็วมากจะไม่ถูกนับ page_view
2. หา Google tag ที่ซ้ำใน GTM container — ถ้ามีแท็ก GA4 Configuration ใน GTM ด้วย หน้าเว็บโหลด gtag 2 รอบ (~200KB เปล่า ๆ)
3. ทำ hero มือถือขนาด 800px (~60KB แทน 130KB)
4. Font Awesome: ใช้แค่ไอคอนที่ใช้จริง (subset/SVG) แทน all.min.css
